Hello Crescendo!


After finishing the basics for the boiler plate code on the Vulkan backend side, I wanted to transition into getting base file importing via GLTF / GLB extension. 
I initially started with .obj, this is still a legacy feature in current Crescendo Bravo. Plans for expanding or implementing our own file format will be decided 
on at later dates / needs of the project. For now we are avoiding FBX as its a nightmare to deal with, god speedbigger engines that do this properly. The below 
attachments are screengrabs I grabbed from the Discord group that was started for the early development cycles if people wish to join we have access in our contact 
tab on the navigation bar.
I still have a long way in terms of format adoption, engine philosophies and other general technical nuances that come with the challenges ahead,
enjoy the screen grabs.
